# Psychometric Analysis in R

Portfolio example demonstrating a structured workflow for reliability analysis and exploratory factor analysis (EFA) in psychological research.

## Context
This is based on skills developed while working on psychometric validation within an ICMR-funded multi-site ageing research project.

**No participant-level data, identifiable information, institutional data, or confidential project files are included.**

## What this demonstrates
- Data preparation and quality checks
- Reliability analysis
- Exploratory factor analysis
- Documentation of analytical decisions
- Organising an R analysis project for reproducibility

## Tools
R · RStudio · GitHub

The included R script is a template using placeholders rather than real study data.
